# Terbang atau naik kereta api tidur ke Luxor dan Aswan?

Sejam di udara berbanding semalaman di atas landasan — dan apa yang masing-masing korbankan daripada tidur anda.

Setiap jadual perjalanan yang menuju ke selatan dari Kaherah perlu membuat pilihan ini sekali bagi setiap hala. Ia lazimnya dilihat sebagai soal masa lawan wang. Bagi kebanyakan pelancong, sebenarnya ia soal bagaimana rasanya pagi esok.

01

## Pendapat kami

Jika keselesaan lebih penting daripada kos, terbanglah. Kaherah ke Luxor kurang sejam di udara dan ke Aswan sejam suku, anda tidur di atas katil hotel, dan tiba dengan cukup rehat. Kereta api tidur memang satu pengalaman sebenar dan bernilai — makan malam, sarapan dan kabin persendirian dua katil — tetapi perjalanannya sepuluh hingga tiga belas jam, tandasnya dikongsi, dan kereta api ke selatan tiba di Luxor kira-kira pukul setengah enam pagi. Pilihlah ia demi pengalaman, bukan demi rehat.

02

## Perbandingan sebelah-menyebelah

- Kaherah ke Luxor — Terbang: Kira-kira 55 minit di udara · Kereta api tidur: Kira-kira 10 jam semalaman
- Kaherah ke Aswan — Terbang: Kira-kira 1 jam 15 minit di udara · Kereta api tidur: Kira-kira 13 jam semalaman
- Tempat anda tidur — Terbang: Bilik hotel · Kereta api tidur: Kabin dua katil dengan sinki
- Bilik air — Terbang: Milik anda sendiri · Kereta api tidur: Dua tandas dikongsi bagi setiap gerabak
- Ketibaan — Terbang: Bila-bila masa penerbangan mendarat — tengah pagi pun mudah · Kereta api tidur: Luxor sekitar 05:35, Aswan sekitar 08:35
- Hidangan — Terbang: Hidangan hotel anda · Kereta api tidur: Makan malam dan sarapan dihidangkan di dalam kabin
- Cahaya siang yang terpakai — Terbang: Sebahagian pagi atau petang · Kereta api tidur: Tiada — anda bergerak ketika tidur
- Bagasi — Terbang: Didaftarkan, tertakluk pada had berat · Kereta api tidur: Bersama anda di dalam kabin
- Sesuai untuk — Terbang: Pelancong lebih berumur, mereka yang mudah terjaga, sesiapa yang kurang bertenaga · Kereta api tidur: Pelancong yang gemar kereta api dan tidak kisah bertolak awal

03

## Terbanglah jika

- Anda lebih rela tiba dengan cukup rehat daripada menjimatkan satu malam
- Ada dalam rombongan yang lebih berumur, mudah terjaga, atau berasa sukar dengan katil yang sempit
- Bilik air persendirian lebih penting bagi anda daripada keromantikan kereta api
- Hari selepas perjalanan ialah hari yang ingin anda nikmati, bukan hari untuk pulih

04

## Naiklah kereta api tidur jika

- Bagi anda kereta api itu sebahagian daripada pengembaraan, bukan sekadar jalan ke selatan
- Anda mudah tidur di mana-mana dan ketibaan awal tidak menjadi masalah
- Anda lebih rela tidak mengorbankan sebarang cahaya siang kepada lapangan terbang
- Anda bergerak dengan bagasi ringan dan suka menyimpan beg di sisi

05

## Harga sebenar ialah pagi esoknya

Hujah untuk kereta api tidur ialah ia menjimatkan satu malam hotel dan satu pemindahan siang hari. Kedua-duanya benar. Yang sukar dilihat pada jadual perjalanan ialah kosnya: semalaman tidur yang terganggu di dalam kereta api yang bergerak dan — ke arah selatan — ketibaan di Luxor sebelum subuh. Kebanyakan orang yang mencubanya sekali menikmatinya. Lebih sedikit yang memilihnya kali kedua, dan hampir tiada yang berbuat demikian bersama ibu bapa yang berumur tujuh puluhan.

06

## Apa yang sebenarnya diambil oleh penerbangan

Masa di udara memang singkat, tetapi perjalanan bukan hanya penerbangan. Hitung perjalanan ke lapangan terbang, pendaftaran masuk dan pemindahan sewaktu tiba, maka penerbangan ke selatan memakan sebahagian besar pagi atau petang. Itulah pertukarannya: sedikit cahaya siang dikorbankan, untuk semalaman di atas katil yang sebenar dan pagi pertama di Mesir Hulu yang bermula dengan sarapan, bukan pada pukul setengah enam.

07

## Cara kami mengaturkannya

Dua daripada perjalanan kami yang lebih panjang — Egypt Icons & Nile Cruise dan Egypt Highlights Deluxe — menggunakan kereta api tidur pada kedua-dua hala seperti yang diterbitkan. Kedua-duanya juga boleh diaturkan dengan penerbangan sebaliknya, dengan dua malam itu di hotel, dengan tambahan €130 seorang; mintalah versi penerbangan semasa membuat pertanyaan. Setiap perjalanan lain yang menuju ke selatan sudah pun dibina berasaskan penerbangan.

## Soalan lazim

### Berapa lama perjalanan kereta api dari Kaherah ke Luxor?

Kira-kira sepuluh jam. Kereta api tidur semalaman bertolak dari Kaherah pada waktu petang dan tiba di Luxor sekitar 05:35 keesokan paginya; kereta api siang mengambil masa yang hampir sama. Belum ada perkhidmatan kereta api laju ke Luxor.

### Berapa lama perjalanan kereta api dari Kaherah ke Aswan?

Kira-kira tiga belas jam. Kereta api tidur bertolak dari Kaherah pada waktu petang dan tiba di Aswan sekitar 08:35. Penerbangan mengambil masa kira-kira sejam suku.

### Bagaimanakah keadaan kabin kereta api tidur?

Petak persendirian dua katil dengan sinki, cadar dan tuala yang bersih, serta makan malam dan sarapan dihidangkan di dalam kabin. Tandasnya dikongsi — dua bagi setiap gerabak — dan kerana ia kereta api yang bergerak, mereka yang mudah terjaga sering mendapati malamnya panjang.

### Adakah kereta api laju ke Luxor atau Aswan?

Belum lagi. Mesir sedang membina laluan kereta api laju di sepanjang Sungai Nil ke Luxor, Aswan dan Abu Simbel, tetapi ia belum beroperasi. Kini pilihannya ialah kereta api konvensional, biasanya semalaman, atau penerbangan.

### Mana satu lebih baik untuk pelancong yang lebih berumur?

Terbang, dalam hampir semua keadaan. Ia kurang sejam suku ke kedua-dua bandar, anda tidur di atas katil hotel, dan tiada katil sempit, bilik air kongsi atau ketibaan sebelum subuh yang perlu diuruskan.
